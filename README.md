# Bet on Your Friends

## What and Why?

Bet on Your Friends is a web app where friends make predictions about things happening in each other's lives using fake money. For example, "Will Alex get an internship by November?" or "Will Sam go to the gym 10 times this month?" The app keeps track of these predictions so everyone can see who was actually right.

## For Whom?

The app would initially be for my friends and classmates at NYU, especially friend groups that already make these kinds of predictions in conversation or group chats.

## How?

Users can create or join a private group, make a prediction, and bet fake coins on the outcome. Once the event happens, the prediction is resolved and the app updates everyone's balance and leaderboard.

## Scope

The project would include user accounts, groups, predictions, virtual betting, and a leaderboard. It is large enough for a team project but still realistic to build within one semester.
